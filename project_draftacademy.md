# Draft Academy

An educational website that teaches data engineering, statistics, and AI engineering through Magic: The Gathering draft analysis, using 17Lands data as a concrete, motivating case study while the underlying skills transfer everywhere. It grew from two design documents (~1,400 lines) that were decomposed into buildable modules and implemented as a fully typed React app with 30 interconnected lessons, 5 learning pathways, interactive quizzes, and a tweet-style content layer. Topics span log parsing and pipeline architecture, win-rate analysis and signal theory, deterministic-vs-probabilistic AI systems and tool-calling, state machines and event-driven architecture, and progressive-disclosure pedagogy.

## Status (2026-06-27)
Live on GitHub Pages; React/Vite app with 30 lessons implemented.
