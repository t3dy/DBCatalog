# EsotericProjectsShowcase

A single-page index of the digital humanities databases, image-processing tools, and games built across this workspace around esoteric, alchemical, and occult scholarship. It groups projects into Knowledge Portals (AtalantaClaudiens, TheosophicalAlchemyDB, MedievalMagicDB, Renaissance Magic DB, WitchcraftStudiesDB, CrowleyDB), Tools & Image Pipelines (EmblemPrintShop, Goetia Sigil Analysis), and Games & Experiments (Digby Game, Tree Tapper, and more), each with a description, status, and link. It functions as the public front door / portfolio for the broader esoteric-DH ecosystem.
