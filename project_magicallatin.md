# MagicalLatin

A gamified Latin reader for magical texts, built as a pure vanilla HTML/CSS/JS static site with no build system. It offers a filterable card grid of 101 passages, word-click vocabulary tracking with multiple scaffold modes, passage modals (Latin, English gloss, vocab, sources), an XP/level system, a flashcard quiz, an Alchemy Lab, ritual walkthroughs, and a Codex/stats modal with achievements; progress persists in localStorage. A coverage requirement ties it to MedievalMagicDB: every concept there must be represented by at least one passage. Medieval dark-gold theme (Cinzel + EB Garamond); dev server on port 5180.

## Status (2026-06-27)
All listed features implemented; ongoing content/coverage cross-referencing against MedievalMagicDB.
