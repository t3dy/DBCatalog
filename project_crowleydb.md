# CrowleyDB

A digital humanities project for organizing, cross-referencing, and exploring the works, life, associates, travels, and symbolic system of Aleister Crowley. Its goal is to make the material browsable, traceable, and transparent about what is documented versus interpretive, keeping source attribution visible so users can distinguish primary records, scholarship, autobiography, and later practitioner interpretation. Main sections cover works and text companions, people/saints/precursors, Tree of Life and correspondences, timeline and locations, plus topic browsing, a corpus catalog, tarot readings, an initiation game, and a character sheet. Architecture: SQLite as source of truth, Python ingestion, static JSON export, React + Vite frontend, GitHub Pages hosting.
