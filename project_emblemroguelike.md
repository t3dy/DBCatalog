# EmblemRoguelike

"Emblem Knight — and the Alchemical Dragon" is a *Dragon Warrior*–style RPG and roguelike whose entire art set is built from the Emblem Print Shop's extracted woodcuts, themed on Michael Maier's *Atalanta Fugiens* (1617). It pairs an NES/SNES-era overworld hub and first-person command-menu battles with a procedurally generated, fog-of-war descent through the four colour stages of the Great Work (Nigredo → Albedo → Citrinitas → Rubedo), each announced with a genuine Maier motto, ending in the Alchemical Dragon and the Philosopher's Stone. Permadeath; choose a vessel (Knight, Alchemist, Atalanta, or Hippomenes). Static, no framework; served via `.claude/launch.json` as **emblem-knight** on port 7431.

## Status (2026-06-27)
Playable online via GitHub Pages with an Asset Codex; grounded in the workspace alchemy databases.
