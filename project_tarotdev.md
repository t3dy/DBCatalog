# Tarot Dev

A tarot knowledge database and (eventually) application built on a dialectical, non-mystical, structurally attentive interpretive philosophy. It treats tarot as a psychological/narrative tool rather than fortune-telling, prioritizes structural reading (suit prevalence, trump density, number sequences) before individual card meanings, keeps multiple traditions (RWS, Thoth, Marseille) stored separately rather than collapsed, frames every interpretation as a dialectical question, and demands full provenance (each meaning traces to a source book and page) with evidence-based history in the Dummett school. Pipeline: PDF corpus → Markdown → SQLite → application (`data/tarot.db`).

## Status (2026-06-27)
Database/pipeline project; interpretive philosophy and ontology documented, application "eventually."
