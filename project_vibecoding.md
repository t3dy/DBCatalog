# Project: Vibe Coding Garage (VCG)

## Overview
**Type**: Community Data Pipeline / Discord Integration
**Path**: `C:\Dev\vibe-coding-garage`, `C:\Dev\VCG_DOCS`, `C:\Dev\VCGdiscord.txt`

The Vibe Coding Garage represents an early exploration into Discord bots and community-driven coding interaction. It acts as an integration layer between individual development workflows and multiplayer/social platforms.

## Architectural Notes
* **Tech Stack**: Discord API integrations, bot tokens, and conversational archiving.
* **Significance**: This project serves as the foundational testbed for the "Social Megaphone" database theory. It represents the attempt to pipe the solitary, highly academic DH framework out into a multiplayer, community-driven space, testing how agentic systems interact with live users and developers on Discord.

## Integration with the Memory System
The massive chat transcripts generated by the VCG (e.g., `VCGTRANSCRIPT1.txt`) were early experiments in capturing collaborative developer data, acting as a precursor to the massive `SocialsDB` and `Megabase` autoethnographic pipelines.
