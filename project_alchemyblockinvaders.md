# AlchemyBlockInvaders

A Space Invaders–style game in which descending enemy blocks embody the four fundamental elements of Paracelsian alchemy — Fire, Water, Air, and Earth. Shooting a block activates the nature of fire within it and triggers alchemical reactions (e.g., Fire + Water → Steam, Fire + Earth → Ash) that transform blocks and produce cascading secondary effects. A "Tome" (spellbook) accumulates the player's discovered reactions and unlocks descriptions, so players learn the secrets of the four elements through gameplay. Standard arcade controls (arrow keys, spacebar to fire), wave progression, and a health system.

## Status (2026-06-27)
Playable arcade prototype with reaction system and Tome; scope per README.
