# neoplatonism-portal

A concept-first encyclopedia of Neoplatonic philosophy spanning roughly 1,400 years from Plotinus through Ficino, designed so users navigate by philosophical idea rather than by chronology or figures. Built on a deterministic-first method (Python extracts provable schema, seed data, and relationships before any LLM enrichment), working from a corpus of 116 PDFs (~896 MB). The roadmap runs six phases over nine weeks — PDF ingestion, schema + seed (50–70 concepts, 30–40 philosophers), entity essays, relationship enrichment, thematic essays, frontend (static site + D3.js), and deployment to GitHub Pages.

## Status (2026-06-27)
Phase 0 (PDF ingestion → markdown + manifest) in progress; later phases pending.
