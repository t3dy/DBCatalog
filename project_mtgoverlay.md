# Project: MTG Overlay Suite

## Overview
**Type**: Legacy Utility / Interface Design
**Path**: `C:\olddevprojects\MTGOverlay`, `C:\olddevprojects\OverlayV2`, `C:\olddevprojects\MTGOverlay2`

A suite of legacy applications originally designed to provide streaming or drafting overlays for Magic: The Gathering gameplay.

## Architectural Notes
* **Tech Stack**: Early web interface and overlay design architecture.
* **Significance**: This is the direct architectural ancestor to the current `Alchemy Scryfall` project. The technical skills developed here for scraping card data and managing MTG visual interfaces were later radically repurposed for pure Digital Humanities methodology—literally using the structural UI of trading cards to map out esoteric Renaissance alchemical traditions.
