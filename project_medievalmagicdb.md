# MedievalMagicDB

A scholarly knowledge portal for medieval magic: learned ritual practice, astral image magic, necromancy, angelic theurgy, grimoires, ecclesiastical critique, manuscript transmission, and modern historiography. It treats "medieval magic" as an analyst category rather than a medieval actor's self-description, distinguishing clerical condemnation, learned natural philosophy, ritual experiment, astral image theory, divination, and demonic magic. It follows the EmeraldTablet framework: SQLite as source of truth, idempotent Python ingestion, Markdown source extraction for token-efficient research, staged JSON enrichment, and static HTML generated into `docs/` and `site/`. Serves as the canonical concepts source that MagicalLatin must cover.
