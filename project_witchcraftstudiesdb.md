# WitchcraftStudiesDB

A comprehensive historical witchcraft-studies knowledge portal combining a relational database (320+ structured JSON entries on trials, accused persons, demonological concepts, primary texts, scholars, and geographic/biographical context), an interactive multi-page website serving scholars/students/researchers, an academic corpus of 30+ PDF-to-Markdown sources, and Python validation/integration tools. It synthesizes three major historiographical traditions — Stuart Clark (intellectual history), Ronald Hutton (social history), and Carlo Ginzburg (microhistory) — while keeping every claim traceable to named sources with confidence levels (HIGH/MEDIUM/LOW) and documented scholarly disagreement. (Note: distinct from the WitcherPortal folklore project.)
